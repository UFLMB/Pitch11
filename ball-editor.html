Ball Studio

Create an original match ball. Paint directly on the 3D surface, add decals and export the texture profile.

3D MODEL
Loads the free Innerscene size-5 ball or a local GLB. Painting requires UV coordinates in the model. The match physics remain unchanged.
BASE COLOUR
PAINT TOOL
Drag on the ball to paint. On mobile, use one finger; rotate the view when the paint tool is off.
DECALS & GRAPHICS
OFFICIAL BRAND EMBED
Add one official PITCH 11 wordmark to the front-facing area. The logo automatically selects a contrasting brand colour for light or dark surfaces.
The logo is baked into the UV texture and included in PNG / JSON exports. Use Undo to remove it before adding it again.
Text and image stickers remain editable after placement and are included in PNG / JSON exports.
DECAL SELECTED
Drag the selected decal directly on the ball, or fine-tune its position, size and rotation here.
FINISH

Current base mesh is a UV-mapped sphere prototype. The editor is structured so a verified CC0 GLB ball can replace it without changing the painting tools or match physics.
