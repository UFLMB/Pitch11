# Player asset package upload

Ide töltsd fel a kész, embermodell nélküli játékoscsomagot.

## Mit tegyél ide?

- Az eredeti ZIP-et, ha egyben van a csomag.
- Vagy a kicsomagolt fájlokat és almappákat, az eredeti mappaszerkezet megtartásával.
- Modellek: `.glb`, `.gltf`, `.fbx`, `.obj`
- Anyagok és textúrák: `.png`, `.jpg`, `.jpeg`, `.webp`, `.tga`, `.mtl`
- Animációk és rigfájlok, ha vannak.
- Licencfájl és forrásmegjelölés, ha a csomag tartalmaz ilyet.

**Fontos:** egyelőre csak feltöltésre szolgál; innen semmi nem kerül automatikusan a játékba. Feltöltés után átvizsgálom a fájlokat, a formátumokat, a licenceket és a kompatibilitást.

A GitHub webes felületén egy fájl feltöltési korlátja 25 MB. Nagyobb fájlt ne próbálj átnevezéssel vagy darabolás nélkül feltölteni; jelezd, és választunk megfelelő feltöltési módot (például Git LFS).
